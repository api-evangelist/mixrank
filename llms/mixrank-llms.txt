# MixRank

> MixRank curates ultra-high-frequency technographic, firmographic, and people data for enterprise data teams. Datasets cover 45M+ companies, 800M+ people, 20M+ iOS/Android mobile apps with SDK-install intelligence, and web technographics across 80M+ websites, delivered via a JSON REST Data API, flat-file feeds, and native cloud shares.

This llms.txt was generated by the API Evangelist enrichment pipeline from MixRank's public documentation; it is not an official MixRank artifact. MixRank serves no /llms.txt of its own (probed 2026-08-14, 404 on both mixrank.com and api.mixrank.com).

## APIs

- [MixRank Data API documentation](https://mixrank.com/api/documentation): JSON REST API over company, people, email, mobile app & SDK (iOS/Play), rankings, in-app purchases, app privacy, and web technographic datasets. API key passed as a URL path segment. Base URL https://api.mixrank.com/v2/json/{api_key}/

## Notes for agents

- Authentication is an API key embedded in the URL PATH, not a header. Never log a MixRank request URL verbatim — it contains the credential.
- Optional parameter names are case-sensitive and a misspelled one is silently ignored rather than rejected.
- There is no MCP server, no A2A agent card, no GraphQL endpoint and no OAuth surface (all probed 2026-08-14).
- MixRank documents no idempotency key. Long-running email calls should use the `webhook` parameter rather than being retried.
